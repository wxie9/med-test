## 首期实施原则

- 患者模型采用显式、可修订的当前表示；长期记忆保存可检索依据和历史；助理按当次任务使用经授权组装的上下文。
- 六个模块是逻辑分工，可先在单一服务中实现，不预设拆分为独立服务。
- 首期建立交互读取、信息更新、纠错失效、异常追溯四条核心流程。
- 首期允许简单同步处理或按主体顺序处理更新，不强制建设复杂异步管线。
- 保留来源关联、版本管理、基础主体隔离和可检查的更新结果。
- 使用抽象主体、模拟事件及接口桩验证最小闭环；真实患者建模质量和临床效果需在后续具备条件后评价。

## 合作分工

顾问牵头架构与机制设计、实施指导和技术评审；工程团队负责代码实现、配置、运行环境及验证材料；CX 项目方提供系统背景并协调接口与范围确认。当前材料是设计与工作范围，不代表工程已交付。
