# CX 患者数字孪生首期总体架构设计与最小闭环验证

版本：统一口径首期范围收敛稿。更新日期：2026-10-21。

## 一、项目目标与合作方式

完成 CX 患者数字孪生首期总体架构与核心机制设计，并由工程团队实施最小技术闭环，验证患者表示跨会话延续、上下文使用、信息更新、纠错及基础隔离能力。

采用**顾问牵头设计、实施指导与技术评审，工程团队负责工程实现与验证，项目方负责资料与环境协调、业务／专业要求确认及阶段交付接收**的合作方式。

顾问交付以架构、机制、流程、验证方案、技术审阅和交接材料为主；工程团队提交约定范围内的实现与验证成果。业务与专业判断由项目方指定的责任人员确认。

## 二、工作内容

### 1. 总体架构与首期范围设计

- 梳理可获得的 CX 现有系统资料，明确与数字孪生框架的接入边界、依赖及待确认事项。
- 设计接入适配、患者模型、证据与长期记忆、上下文组装、助理运行时及受控更新等逻辑模块。
- 明确模块职责、读写关系和生命周期，区分患者主体、助理身份及会话状态。
- 确定首期最小范围、设计假设及后续扩展位置。

### 2. 核心对象与管理机制设计

- 定义患者当前表示、长期记忆和原始证据之间的关系。
- 明确已有依据、候选判断、未知及冲突信息的表达与处理原则。
- 设计来源关联、版本管理、更新提交、信息替代及失效机制。
- 明确基础主体隔离、访问权限、过程记录和更新结果确认要求。

### 3. 关键流程与接口约定设计

- 设计交互读取流程：请求接入、身份确认、患者表示与记忆读取、上下文组装、助理输出及记录。
- 设计信息更新流程：来源登记、候选信息产生、规则校验、记忆或状态提交及版本发布。
- 设计纠错与失效流程：定位来源、识别直接影响、修订或失效及后续使用内容刷新。
- 设计异常与追溯流程：读取、模型调用、更新失败及重复提交处理。
- 明确模块间接口原则、结果状态、预期行为及验证记录要求。

### 4. 工程实施指导与技术评审

- 向工程团队说明总体架构、核心机制和接口约定。
- 评审约定范围内的工程实现方案，识别与设计不一致的部分。
- 对实施中的架构、接口、运行配置及范围变化提出处理建议。
- 根据评审与验证结果修订设计，记录关键决策、处理结论和遗留事项。

### 5. 最小闭环验证与交接

- 定义验证场景，指导工程团队使用抽象主体、模拟事件和接口桩开展验证。
- 审阅跨会话延续、上下文使用、更新提交、纠错失效、主体隔离及异常处理的验证结果。
- 按验证结果修订设计，整理已验证与未验证内容、已知限制和后续依赖。
- 完成方案讲解、评审意见处理和阶段交接。

## 三、阶段交付物

### 1. 顾问牵头交付

| 交付物 | 主要内容 |
| --- | --- |
| 《CX 首期总体架构与范围说明》 | 架构图、模块职责、接入边界、依赖关系、首期范围、设计假设及待确认事项 |
| 《CX 核心机制、流程与接口约定》 | 核心对象关系、读写责任、来源与版本机制、交互读取、信息更新、纠错失效及异常追溯流程、接口与权限原则 |
| 《CX 框架验证方案与技术评审记录》 | 验证场景与预期行为、工程方案评审意见、过程与结果审阅结论、问题处理记录 |
| 《CX 首期总结与交接说明》 | 最终设计结论、已验证与未验证内容、已知限制、遗留事项及后续建议 |

上述内容可合并成统一文档包，不要求拆成多个独立文件；各项内容按约定阶段形成、评审和修订。

### 2. 工程团队配套交付

**最小框架实现与验证包**包括：

- 约定范围内的源代码、配置模板及运行说明。
- 最小接入或任务适配、抽象／模拟输入、接口桩及验证用例。
- 核心流程运行记录、版本关联、验证结果及异常处理记录。
- 问题修复记录、必要的恢复或回退说明及已知工程限制。

工程成果由工程团队实施并提交，顾问负责设计指导与技术审阅；实现边界以本项目首期范围说明为准。

## 四、首期范围与验证边界

首期以**显式患者表示、基础长期记忆、单一助理运行方式及可追溯的更新闭环**为实施基线。优先采用简单、可复现的工程结构，逻辑模块可合并实现。

患者专属模型训练、复杂画像推断、知识图谱、多 Agent 协作、预测与情景推演、主动业务执行、外部系统自动回写及生产高可用等能力后置。

本期聚焦框架与流程，暂不细化患者数据字段、具体临床业务功能和专用算法。框架验证使用约定环境、抽象或模拟输入及具备条件的接口，记录实际验证层级。

框架交付关注流程可验证、结果可追溯及边界明确。真实数据适配、实际院内联调、生产实施和临床效果评价在条件具备后另行明确。

本版暂不确定具体时间与费用。并行推进与顺序推进仅调整组织和阶段衔接，均沿用本项目相同首期范围及交付要求，详见[并行推进版](../cx-dx-sow/parallel.md)和[顺序推进版](../cx-dx-sow/sequential.md)。
