# CX 与 DX 首期 SOW 推进版本

本目录提供两份可独立阅读的推进版本，工作内容、交付物、分工、阶段和范围边界保持一致，区别集中在第七部分的组织与衔接。

- [版本一：并行推进](parallel.md)：两个项目分别设立工作线，阶段与交付可以错开。
- [版本二：顺序推进](sequential.md)：先行项目完成约定首期交付及交接后，再启动后续项目，兼容 CX→DX 或 DX→CX。

详细单项范围见 [CX 首期 SOW](../cx-digital-twin/phase1-sow.md) 和 [DX 首期 SOW](../dx-self-improvement/phase1-sow.md)。两份单项 SOW 已采用统一的五项工作内容、四类顾问交付物与责任分工。后续范围变化需同步更新单项 SOW 与对应推进版本。

本轮为方案与范围讨论，不列具体时间、持续时长和费用，不生成 Word。未实施工程验证，文中工程包为拟约定交付要求。
