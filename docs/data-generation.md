# 合成数据生成说明

本演示的全部患者数据均为合成数据，不对应任何真实患者，也不代表任何真实人群的分布。本文描述 `lib/seed/generator.ts`（生成器版本 gen-v2）的实际实现；文中比例均为种子 20261013 下的实测值。

## 1. 种子、版本与校验值

| 项 | 值 |
|---|---|
| 随机种子 | 20261013 |
| 生成器版本 | gen-v2 |
| 数据截止日 | 2026-10-13 |
| 队列 checksum | c2b1c6d314bd4143（`cohort.json` 的 SHA-256 前 16 位） |
| 数量 | 锚点 12、批量队列 2000、异常病例 20 |
| 硬约束违规 | 0（锚点 + 队列） |

- 以上信息写入 `data/seed/manifest.json`，首页"数据清单"同步展示。
- `npm run seed` 重新生成 `cohort.json`、`edge-cases.json` 与 `manifest.json`；种子、版本、截止日不变时 checksum 不变。生成时先对锚点与队列运行硬约束校验，有任何违规即退出、不写文件。
- `cohort.json` 与 `edge-cases.json` 不入库；`npm run demo` 在文件缺失时自动执行 `npm run seed`。

### 2.2 批量合成队列（2000 例，P-0001～P-2000）

由生成器按疾病状态机与时间约束逐例生成，不是各字段独立随机。阶段分布：早期辅助 1410、转移性 285、生存期 137、失访 79、死亡 89。

### 2.3 异常病例（20 例，E-01～E-20）

以种子 1 生成 20 例后按序号轮流注入四类硬违规：结束日早于开始日、重复事件、辅助治疗早于手术、死亡后仍有事件。20 例全部被校验器检出（共 42 条违规）。异常病例只用于测试，不加载进演示状态。

## 3. 分布参数（gen-v2 实现）

### 3.1 人口学与病理
- 年龄 32～78 岁均匀；诊断日为截止日前 120 天～7 年；手术为诊断后 14～45 天；入组为诊断后 30 天。
- 分型抽样：65% HR+/HER2-，其余中 57% 为 HER2+、43% 为三阴性。HER2+ 中 55% 为 HR+。
- ER 10～100%、PR 0～90%（HR+ 时）；Ki-67 5～70%。
- 非 HER2+ 的原发 IHC 从 {0, 0, 1+, 2+} 等概率抽取；IHC 2+ 中 95% 有 ISH 阴性，5% 未做 ISH。
- 病理分期从 pT1N0M0、pT2N0M0、pT2N1M0、pT3N1M0、pT3N2M0 中等概率抽取。
- 标本 2023-01-01 前判读版本记为 ASCO/CAP2018，之后为 ASCO/CAP2023。

### 3.2 辅助治疗
- 非 HR+/HER2- 或淋巴结阳性者行 AC-T 辅助化疗（术后 21～130 天）。
- 所有 HR+ 患者行辅助内分泌（来曲唑 / 阿那曲唑 / 他莫昔芬），化疗结束后 10 天开始，无化疗则术后 40 天。
- HER2+ 行一年曲妥珠单抗（术后 21～386 天）。

### 3.3 复发、转移与晚期治疗
- 远处转移年风险：N2 12%、N1 7%、N0 3%，三阴性再乘 1.6；转移日不早于术后 150 天。转移后开始的辅助治疗删除，跨过转移日的辅助治疗截止于转移日并记为进展。
- 转移灶活检中 30% 重新抽取 HER2 IHC（0 / 1+ / 2+）。
- 一线在转移后 10～30 天开始，持续 90～700 天：HR+ 为氟维司群 + CDK4/6 抑制剂（哌柏西利 / 阿贝西利 / 达尔西利），HER2+ 为曲妥珠单抗 + 帕妥珠单抗，三阴性为白蛋白紫杉醇。
- 一线进展后 10～40 天开始二线，持续 60～400 天：转移灶 HER2 3+ 用德曲妥珠单抗，0 用戈沙妥珠单抗或卡培他滨，其余用德曲妥珠单抗或戈沙妥珠单抗；二线结束时 25% 记为毒性停药。
- 死亡仅可能发生在二线进展之后（35%，进展后 20～200 天）。
- 生存期：无转移且辅助内分泌开始已满 5 年（1826 天）者 50% 转入生存期，内分泌在满 5 年时以"完成"结束。
- 失访：每例 6% 抽中；末次联系 = 最晚已知日期 + 0～100 天，且必须早于截止日 200 天以上才成立，所有进行中事件在末次联系日以"失访"结束。

### 3.4 知情同意、基因、PRO 与依从性
- 随访同意 100%，院内研究同意 90%，药企去标识化同意 80%（研究快照只纳入同意药企去标识化者）。
- BRCA 10% 阳性；PIK3CA 仅在转移性患者中 70% 检测；ESR1 未检测。
- 早期辅助内分泌进行中的患者：最多 6 次月度问卷（关节痛 0～3，潮热、情绪、睡眠 0～2；8% 有停药念头，25% 报告近两周漏服 1～6 次），近 60 天自报服药打卡（每日漏服 7%，其中 70% 填写原因：忘记 / 关节痛 / 外出）。只生成自报打卡，不生成 PDC/MPR。
- 转移性且有进行中治疗的患者：最近 4 周的周度治疗问卷。
- 生成器不内置任何"依从性 → 复发"的关联。

## 5. 硬约束清单（`lib/seed/validate.ts`）

1. 治疗事件结束日不得早于开始日。
2. 转移性意图的治疗必须在某次远处转移事件当日或之后开始。
3. 辅助治疗不得早于手术日开始。
4. 新辅助治疗必须在手术日之前开始。
5. 辅助治疗不得在首次远处转移后开始或结束（未结束视为延续到转移之后）。
6. 化疗与内分泌治疗时间不得重叠（未结束视为无限延续；允许内分泌与 CDK4/6 联合）。
7. 有死亡事件则阶段必须为"死亡"，反之亦然。
8. 死亡之前必须有远处转移、进展或局部复发事件。
9. 死亡之后不得有其他结局事件、治疗开始、进行中治疗、PRO 提交或服药打卡。
10. 阶段为"转移性"必须有远处转移事件。
11. 同一患者内治疗事件 ID 不得重复。

## 6. 派生规则

- **治疗线（lines-v1）**：只取转移性意图且开始日非空的系统治疗（化疗、内分泌、抗 HER2、CDK4/6、ADC），按开始日排序；与当前线开始日相距 ≤ 28 天的事件并入当前线，> 28 天开新线。v1 不参考停药原因，也不比较结束日。生成队列的线状态为"未复核"，锚点为"已复核"。
- **HER2 分类**：IHC 3+ 为阳性；2+ 且 ISH 阳性为阳性、ISH 阴性为低表达、未做 ISH 为不可判定；1+ 为低表达；0 为 HER2-0。当前分类取最新标本，同日时转移灶优先于原发。超低表达本版未单独标记。
- **HR 阳性**：ER ≥ 1% 或 PR ≥ 1%。
- **`enteredAt`**：检测结果录入系统的日期，缺省表示与取材日相同。研究快照按数据截止日冻结时，`enteredAt` 晚于截止日的检测结果不纳入快照（锚点 P-L 用于演示这一点）。

## 7. 不支持的推断

本数据集只用于演示流程与界面，以下结论**不能**从中得出：

- 疗效比较：任何治疗方案、药物或治疗线之间的有效性比较。
- 依从与复发的因果：生成器未建模依从性与复发的关系，依从性页面的任何关联都不构成发现。
- 生存估计：rwPFS、总生存等时间—事件估计不可用；演示队列事件数不足时页面显示"不可估计"。
- 任何真实人群外推：分布参数为演示设定，不代表中国或任何医院的真实患者构成。
- ECOG 体能状态：数据源没有 ECOG 字段，入组漏斗中该条件一律为"需现场核查"。
