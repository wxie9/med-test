# 乳腺癌全生命周期平台 · 演示脚本（12–15 分钟）

全部数据为合成数据（种子 20261013，生成器 gen-v4，checksum cc3217fe1d251f10，数据截止日 2026-10-13）。下文"预期看到"中的人数优先引用 `data/seed/expected.json` 的 key；其余数字为当前种子下按本脚本操作后页面实时计算的结果，若种子或生成器版本变化，以页面为准。锚点病例与指南要点库均为演示转述，**待专家审阅**。

**统计一致**的演示口径：队列圈选页的命中人数 = 同一筛选"导出 CSV"的数据行数 = `/api/cohorts/preview` 返回的人数 = 单元测试中 `expected.json` 的断言（`tests/unit/compute.test.ts`、`tests/unit/cohorts-route.test.ts`）；研究助手只回答**快照**人数，它报告的 n 与数据治理台快照卡片、研究门户概览页的 n 一致。研究助手不复算队列圈选页的人数（快照只纳入同意药企去标识化使用者）。

## 演示前检查

1. 终端执行 `npm run demo`（首次启动会自动生成种子数据），等待出现 Ready。
2. 浏览器打开 `http://127.0.0.1:3000/`（本机若无法解析 localhost，一律使用 127.0.0.1）。
3. 在首页点击 **一键重置**，确认"状态版本"数字加 1，数据清单显示版本 gen-v4、checksum `cc3217fe1d251f10`、已加载患者 2012。一键重置同时清除浏览器里记住的演示患者、工作台身份与已读消息。
4. 确认右上角 ModeBadge：未配置模型密钥时显示"本地演示模式"；配置了密钥则显示 Claude 或"兼容模型"。配置了密钥的，演示前请用三个助手的快捷问题各试跑一次：每条回复要么正文逐字复用服务端事实句，要么在对话框顶部显示带中文原因的降级提示并改用本地模板作答，两者都是预期行为；若每个问题都降级，先检查密钥、模型名与配额，再看提示中的原因。
5. 访问 `http://127.0.0.1:3000/api/state`，确认返回 JSON 且 `patientCount` 为 2012。
6. 投屏分辨率设为 1920×1080 或 1440×900，浏览器缩放 100%。
7. 建议在 `.env.local` 中设置 `DEMO_FIXED_NOW=2026-10-13T10:00:00+08:00`：服务时段（08:00–18:00）内患者端显示"个案管理师将在 1 个工作日内联系您"，夜间则显示急诊提示，固定时间可保证话术一致。

```bash
npm run demo
# 另开终端（可选）
curl http://127.0.0.1:3000/api/state
```

## 故障应对

- **模型降级**：未配置密钥、网络错误、401/403、429、超时（8 秒）、输出校验失败或回复被截断 / 拒答时，助手自动切换为本地演示模式，对话框顶部提示"已切换至本地演示模式（原因）"。话术："数字始终来自计算服务，模型只负责措辞；本地模式用同一套工具结果填充模板，答案仍随患者与快照变化。"
- **网络断开**：整个演示只依赖本机服务，断网不影响任何页面；ModeBadge 显示"本地演示模式"即为预期。若浏览器打不开页面，检查终端里的 `npm run demo` 是否仍在运行，并改用 `http://127.0.0.1:3000`。
- **已关闭预警位置变化**：本页会话中关闭的预警留在原行显示"已关闭"；刷新页面后，已关闭预警移入折叠的"已关闭（N）"区域，点开即可看到。
- **快捷问题不同**：患者管家与医生助手的快捷问题随患者阶段变化（早期 / 晚期），"参加临床研究需要注意什么？"在任何阶段都在。
- **患者 B 不是候选**：属预期（XX-ADC-301 排除既往 ADC，见闭环一节）；确认名单中的任一候选后，用该行的 **打开患者视图** 切换到该患者。
- **第二个快照点错了队列**：在治理台按队列名称找到"早期辅助内分泌在治"卡片再创建；快照编号按创建顺序递增，点错时一键重置后从 v1 重来。
- **数据被前一轮演示污染**：回到 `/` 点击 **一键重置**（或 `curl -X POST http://127.0.0.1:3000/api/reset`），快照编号会重新从 v1 开始。
- **夜间演示**：18:00–08:00 提交高风险问卷时患者端显示急诊提示与值班电话（mock），属预期行为；如需白天话术，设置 `DEMO_FIXED_NOW` 后重启服务。
