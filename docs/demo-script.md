# 上市后患者支持项目（PSP）· 演示脚本（10–12 分钟）

主线约 11 分钟：药企项目 → 患者反馈 → 人工服务与医生复核 → 固定服务快照 → 报告退回修订与双签 → 交付 → 客户验收。原患者/研究/候选闭环保留在文末可选附录，不计入这 11 分钟。

全部临床与 PSP 数据为合成数据，药企、服务目标、身份和交付渠道均为模拟。软件会实际保存演示状态、计算指标及生成固定文件；页面上的电话记录不代表真实拨号，交付不代表已发送给外部客户。锚点病例、指南转述及教育素材仍待真实专家审阅。

## 演示前检查（不计入 11 分钟）

1. 手工演示可用 `DEMO_FIXED_NOW=2026-10-13T10:00:00+08:00 npm run demo`，默认打开 `http://127.0.0.1:3000/`。Task 12 默认验收地址为独立 Next `http://127.0.0.1:3112/` 和本地 Worker `http://127.0.0.1:8787/`。这些是同一应用的两个运行环境；本脚本中的相对路径均接在当前环境之后。验收配置和启动命令以实施报告记录的实际运行方式为准。不要复用时间未确认的旧服务，也不要把会写入/重置的测试指向公共 Workers。
2. 固定服务器时间为 `2026-10-13T10:00:00+08:00`，返回 UTC 时间应为 `2026-10-13T02:00:00.000Z`。在首页执行一次“一键重置”，确认状态版本更新、临床 gen-v4 / checksum `cc3217fe1d251f10`、2012 名合成患者。重置影响当前运行环境中的共享演示进度。
3. PSP 独立种子为 `psp-v1`，checksum `6ab9eaf94182b2559e2155b78d946d955960224c7317fb29a31dda74886fd71a`。内部初始 20 名候选、18 名有效服务成员、14 名允许汇总、54 项固定计划。药企端只展示被允许的汇总口径，不公开内部 18 人与差额明细。
4. 患者 P-A 初始已加入项目并有服务/汇总授权。10 月项目问卷未完成，固定截止为 10 月 13 日 09:00；本次 10:00 填写会标“迟交”。不要在主线先撤回授权或用通用问卷替代项目计划入口。
5. 报告期间开始填 `2026-10-01T00:00`、期间结束（不含）填 `2026-11-01T00:00`、数据截止填 `2026-10-13T10:00`，均为上海时间。这是“10 月阶段服务报告”，不是整月已完成业绩。
6. 默认使用无密钥确定性助手。右上角 ModeBadge 显示配置模式；单条回复是否降级要看该回复的中文提示与响应模式，不能仅凭徽标推断模型调用。演示前核对本次回复模式，验收时单独记录实际模式与降级证据。PSP 报告始终由确定性模板生成，无需在线模型。
7. 建议投屏 1440×900 或 1920×1080、缩放 100%；窄窗口验收覆盖 390/640/755/800/1024/1280/1440/1920px。实际验收覆盖与代表截图在实施报告中记录。患者端使用手机外框，进入每个表单前核对当前患者 P-A。

本地 Next 状态在进程内存中，重启回种子；Worker 通过单个共享 Durable Object 保存状态，停止后使用同一持久化目录重启应恢复原进度。Worker 的“一键重置”会影响所有访问者。需要从头重演时明确重置，不要把“重启”当成两种环境通用的清理方法。

## 可选 PSP 分支与故障应对（不计入 11 分钟）

- 服务授权与汇总授权：患者首页支持项目卡分别控制两种授权。撤回汇总仍可接受服务；撤回服务会暂停成员。撤回实际汇总来源会阻止旧报告后续读取/下载，保留内部历史；重新授权不恢复旧来源，也无法收回已下载副本。授权负向演示放在主线之后或独立重置环境。
- 问卷/自报修订：完成后走显式“修订项目问卷”；今日项目服药从支持卡“查看项目服药自报”进入，再显式“修订最新自报”。普通 `/patient/pro`、无 enrollment 参数的 `/patient/adherence` 仍为原通用功能，不完成项目计划。历史副本导入和联系补录须显式操作；补录经数据审核核验后只供后续新快照采用。
- 联系失败：先记录“无人接听”，可见一次失败尝试、常规联系计划仍待办；再次已接通是另一 interaction。不要用接单或失败尝试冒充成功联系。
- 客户修改请求：药企填写必需理由后“请求修改”；项目经理创建新修订、重新双审、重新交付。交付与客户验收是两个动作。
- 503 或响应丢失：保持当前身份、患者及表单，使用页面的“重试同一次提交”或“重试同一次操作”，回放相同请求。409：刷新并人工核对最新对象/项目账后再继续，不连续新建请求强行覆盖。重置、换患者/身份后不要回放旧 seed 请求。
- Worker 保存失败或压缩状态容量超限（2 MiB 预留 1024 字节，实际保存上限 2096128 字节）：页面应显示失败；恢复后的 GET/重启与实际持久化状态一致。不要讲成“失败但已成功提交”，也不要为继续演示直接清除未知结果；先核对原请求回执。必要时有意识地重置整个共享演示。
- 模型模式：无密钥直接使用确定性模板，不算故障降级。有配置时，部分患者安全/研究定量问题仍由服务器安全模板直接回答；ModeBadge 表示配置，不能证明调用在线模型。其它在线请求遇到网络、401/403、429、配置缺失、超时或输出校验失败时切换本地模板，顶部有中文原因。provider 总预算为 7.5 秒、max_tokens 为 1500；截断、拒答或过滤输出也降级。数字与引用仍由受控工具事实校验。
- Claude 适配器当前配置 `claude-sonnet-5-5`；兼容接口模型名由 `DEMO_OPENAI_MODEL` 指定。这里说明源代码配置，不声称真实密钥/模型可用性已测试。PSP 报告不调用这些 provider。真实线上试用如有安排，应单独记录结果，不能把模拟响应测试当成已调用真实模型。
- 断网：依赖和浏览器安装完成、且本机 Next/本地 Worker 已运行时，无密钥演示无需外网；访问托管 Workers 仍要有网络。若本机页面打不开，检查服务进程和正确端口。夜间话术依赖服务器时钟，固定到预检时点以便复现。
