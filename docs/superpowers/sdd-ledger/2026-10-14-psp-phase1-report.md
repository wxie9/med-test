# PSP 第一阶段实施与验收记录

日期：2026-10-14。代码基线 `9f8364a`，独立分支 `codex/psp-project-foundation`。本阶段按用户授权实施计划 Task 1–2；Task 0 的安全构建与 lint 修复沿用既有提交。Task 3–12 继续保留为后续计划。

## 已实现范围

- **药企项目入口**：首页和顶栏进入 `/pharma/projects`，项目详情 `/pharma/projects/PSP-BC-ENDO-001`。显示虚构药企/项目范围、固定周期、截止时间、模拟联系目标和受小样本保护的当前允许汇总人数；报告明确为空。原 `/research` 支线保留。药企页面及 ModeBadge 仅调用 `/api/pharma/projects*`，不读取通用或内部状态。
- **患者独立授权**：患者首页和计划页展示当前姓名、项目、两项独立服务/汇总授权、版本化授权历史及固定计划。汇总授权撤回不停止服务；服务授权撤回在同一命令中暂停 active 成员。研究同意不会替代 PSP 授权。非项目患者有空态。
- **内部服务台**：`/clinic/projects/PSP-BC-ENDO-001/services` 区分服务成员和待加入成员。初始候选 20、有效服务 18、允许汇总 14；医生确认适用性，个案管理师/项目经理按合法状态转换激活、暂停或退出。激活必须先有服务授权及医生确认。退出不能直接重新激活，历史计划和原临床随访保留。
- **固定计划**：初始 18 人各三项问卷/联系/教育计划，共 54 项。到期时间来自独立 fixture，10 月项目问卷均未提交。10 次成功联系和 10 份教育反馈是明确的合成背景，不伪造实际服务写入。授权 grant 本身不产生计划；新激活邀请者从固定项目日历选择未来一期，当前固定时钟下三项均为 11 月，原成员 10 月计划不变。本阶段项目计划只读，没有接到通用 PRO 提交。
- **命令与视图边界**：严格输入、模拟 role/actor 匹配、成员版本 CAS、seed 版本、幂等回执、隔离副本提交。失败不留半状态；相同请求重试先回放回执再检查对象版本，同 ID 换内容返回 400，版本/重置冲突返回 409。患者仅投影自己的记录；内部与药企 DTO 分开，药企无个体、内部候选/服务人数或来源账字段。0 人和 1–4 人不外发精确人数。
- **持久化与恢复**：独立 `psp-v1` fixture、SHA-256 manifest 和统一 runtime 清单；PSP 两文件参与安全构建及全部种子指纹。应用 payload schema v2 / `demo-v2` key，旧共享 v1 演示状态升级后初始化，DO 类/迁移标签不变。严格验证嵌套临床及 PSP 结构和账本一致性，恢复 Map 并重新冻结研究快照/批准教育内容。持久化成功后响应；不确定写结果重读 durable，恢复失败清空暂存并阻止后续业务执行，直到恢复成功。
- **界面及请求竞态**：390px 医生导航重排且保留全部入口，手机框响应宽度。URL patient 优先于浏览器旧选项并跟随 query 变化。旧请求/回调不跨患者、身份、项目或 seed 重置生效；409 刷新、永久错误释放操作、503/网络失败复用原请求重试。

## 关键实现决策

1. 不把尚未实现的 PSP 快照/报告实体放进活动状态；药企 DTO `metrics`/`reports` 明确为空。研究快照和批准教育内容按已有不可变规则冻结。
2. 项目发生/入账时间由服务端生成，本阶段拒绝客户端自定义发生时间。日期展示统一上海时区。
3. 新加入患者不追溯承担当期已过期计划。固定日历为 10–12 月每月问卷 13 日、联系 8 日、教育 10 日的 09:00；各类型选择未到期槽位，而非当天加若干天。暂停/退出不删除已有责任。
4. 授权人数只是当前资格概况。月报指标、批次冻结和审核交付未开放，不能用实时授权人数替代阶段报告分母。

## 独立审查与修复

完整独立审查和就地复审见 [代码审查记录](2026-10-14-psp-phase1-code-review.md)。审查发现并已修复：

- schema 严格字段校验之外，恢复时须验证成员状态与完整 membership 账一致；active 必须具备确认和最新服务 grant。补联系/教育事实不早于建立计划及回执版本边界。校验不依赖恢复主机当前时间。
- 同 URL 下保留的旧 command 回调可能读取 reset 后的新 seed；现绑定渲染时 seed 并发送前再次核对，旧回调不再 POST，通知也绑定访问 token。
- README 补 schema v2/key 升级重置及失败恢复行为。

复审无开放问题；独立执行 9 文件 / 43 项测试通过。
