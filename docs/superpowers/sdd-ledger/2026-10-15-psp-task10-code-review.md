## 最终规格与质量结论

- [交付服务](../../../lib/psp/delivery.ts)先核对模拟身份和目标，再精确回放旧回执；新动作继续校验 CAS、最新版本和当前来源。交付仅内部 PM 路由允许，且要求同版数据/医学双签；客户只可 accept/request_changes，修改后新 draft 完整重审。
- 事件投影和恢复校验绑定报告/快照/摘要/模板/算法/保护版本及历史前缀；提交、首签、交付和客户回执保持当时结果。旧创建回执仍为原 draft/v1。可选 reportActions 扩展和 deliveryArtifacts 不回填旧数组，不更换 schema/key/seed。
- [固定交付文件](../../../lib/psp/deliveryArtifact.ts)只含保护白名单正文、结构化安排、角色/时间与交付元数据，保存可读 UTF-8 文本及 SHA-256。反馈与当前门控不改原字节；文本下载用原文，HTML转义同一文本。恢复验证互相绑定的事件/文件/回执并深冻结。
- 当前来源按快照实际 aggregate 贡献及 grant 区间判定，来源资格和读取可用性分开；内部18人或仅支撑来源不会一律撤销报告。服务-only 撤回保留合法汇总历史，重新 grant 不恢复已撤回旧区间。新冻结 `current_grants_v1` 仅投影 aggregate，内部历史和完整来源闭包保留；策略纳入摘要/恢复校验，旧无标记快照保留缺失与原语义。
- [外部投影](../../../lib/psp/pharmaView.ts)每次先读当前 gate，概览只列曾交付版；受阻响应不含旧正文/窗口/摘要/签署/文件。报告/下载严格绑定路径、周期、seed/auth和模拟身份，拒绝额外/重复query，成功/错误/下载禁缓存。事实包另排除客户自由文本，不引入模型/provider；外部旧反馈回执只含状态，不回放正文。
- [共享 hook](../../../lib/client/usePspState.ts)与[药企报告组件](../../../components/psp/PharmaReport.tsx)共同维护有效访问的单调版本下限：旧 seed/auth、退休 URL/token 和延迟解析的错误不能恢复正文或重试。父级屏障在刷新前安装，503卸载子组件不丢失；匹配/更新版本可恢复，项目/报告切换退休旧回调。CAS409须新鲜成功GET后人工核对，503保留同请求重试。
- 最小 PM 交付及药企预览/下载/反馈/验收界面已存在，完整工作台与合并时间线仍为 Task 11。文档保留合成数据/模拟身份及无真实报告发送、模型新增、推送或部署的边界；没有将历史统计当作当前执行结果。
